Startup chart withdrawn

This page used to chart “Selvr vs React” parse time. The React, Vue, Angular, and Next.js rows were filler generated to a target size, and the Selvr row was a hand-shrunk JavaScript file timed with the browser’s parser. That measures small files against large files. It does not measure Selvr.

The replacement is selvr bench, which compiles and runs the real programs.
