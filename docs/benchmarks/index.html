Selvr

Benchmarks

The numbers come from selvr bench. It compiles fib.self, sieve.self, and matmul.self with the real CLI, runs the bytecode on selvr-vm, runs the emitted JavaScript in Node, and runs the same algorithms in plain JavaScript. 

cargo run -p selvr-cli --release -- bench

The VM measured here is the native bytecode interpreter. It is not hosted inside WebAssembly, and it does not skip parsing in the browser: the JS backend still emits JavaScript, which Node parses and JIT-compiles. On these loops the interpreter is expected to take longer than V8.

What is checked

  • fib(10) = 55, then the timed run is fib(40) repeated.
  • sieve(10) = 4, sieve(100) = 25, sieve(10000) = 1229.
  • A 2×2 matmul sums to 2.75. The timed run is 32×32. All three implementations have to agree.

Compile times

docs/benchmarks/compile.sh times selvr build --emit js and selvr build --emit bc on generated files of N tiny functions. Those files are not an application. If selvr is missing, or a compile fails, the script stops. tsc and esbuild are timed only when they are installed.
