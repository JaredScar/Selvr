Selvr

Benchmarks

This page runs fib, sieve, and matmul in your browser. selvr-js is the JavaScript produced by selvr build (selvr/fib.js, selvr/sieve.js, selvr/matmul.js). selvr-vm is the Selvr bytecode interpreter, compiled to WebAssembly, executing the .vlxc files from selvr build --emit bc. plain-js is the same algorithm written by hand.

Each cell is the median time of one call, from 5 samples. A sample repeats the call until the batch lasts at least 8 ms, then divides by that count, so the browser timer can see short JavaScript loops. The VM is loaded again before each sample; that reload is outside the clock. Matrix inputs are built outside the clock. vm / plain is the interpreter time divided by the plain JavaScript time. On these loops the interpreter is expected to take longer than the JavaScript engine.

The numbers are measured in your browser when the page runs. selvr bench times the same interpreter as a native binary. Calls from this page pass arguments as JSON: 

cargo run -p selvr-cli --release -- bench

What is checked

  • fib(10) = 55, then the timed run is fib(40) = 102334155.
  • sieve(10) = 4, sieve(100) = 25, sieve(10000) = 1229.
  • A 2×2 matmul sums to 2.75. The timed run is 32×32. All three implementations have to agree.

Compile times

docs/benchmarks/compile.sh times selvr build --emit js and selvr build --emit bc on generated files of N tiny functions. Those files are not an application. If selvr is missing, or a compile fails, the script stops. tsc and esbuild are timed only when they are installed.

Withdrawn

The old startup, time-to-interactive, and hybrid pages did not measure Selvr. They compared filler bundles, handwritten loops, and a WASM module assembled in the page. They are kept only so old links explain that.
